One letter, one answer: **A — coffee**. The bounty asks for exactly one letter, A for coffee or B for tea, and a judge picks the more vivid, funnier, truer one. Coffee is the bolder, darker, more alive answer — the morning jolt, the cup that talks back before you can — so this entry sends `A`, nothing else, no word, no punctuation. `main.py` writes that single letter to `/output/entry.txt` and verifies it is exactly one character before finishing.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
